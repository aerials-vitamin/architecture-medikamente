#### Список инструментов, способов и мер для обеспечения конфиденциальности данных

1. **Разработка и внедрение Медицинской Информационной Системы (МИС):**
    * Централизованное хранилище всех данных пациентов (ПДн, мед.карты, анализы, записи).
    * Отказ от Excel и разрозненных сканов.
    * **Технологии:** PostgreSQL (pgcrypto).
2. **Обеспечение безопасности на уровне СУБД (PostgreSQL):**
    * **Шифрование:** Шифрование всей базы данных на диске.
    * Настройка прав доступа на уровне ролей БД, схем, таблиц, колонок.
3. **Обеспечение безопасности на уровне приложений:**
    * **RBAC / ABAC:** Чёткое определение ролей (врач, ресепшен, пациент, администратор) и их прав доступа к данным и функциям.
    * **Аутентификация и Авторизация:** Надёжные механизмы (например, OAuth 2.0 / OpenID Connect). MFA для сотрудников.
    * **Шифрование в транзите:** Использование HTTPS (TLS 1.3) для всех веб-коммуникаций.
    * **Input Validation:** Защита от SQL-инъекций, XSS и других веб-уязвимостей.
    * **Логирование действий пользователей:** Подробный аудит всех операций с чувствительными данными.
4. **Сетевая безопасность:**
    * **Межсетевые экраны (Firewalls):** Контроль трафика.
   * Контроль использования съёмных носителей.
5. **Управление данными:**
    * **Политики Data Minimization:** Сбор только необходимых данных.
    * **Политики Data Retention and Deletion:** Определение сроков хранения и процедур удаления данных.
    * **Резервное копирование:** Регулярное, шифрованное, с проверкой восстановления. Хранение копий в безопасном месте.
6. **Интеграции:**
    * **API лаборатории:** Использование защищённых протоколов (HTTPS), аутентификация API-ключей или OAuth2 client credentials, передача только минимально необходимых данных.
7. **Защита 1С (переход на клиент-сервер):**
    * Перевод "1С Бухгалтерия" и "1С Торговля и склад" в клиент-серверный режим.
    * Настройка прав доступа внутри 1С.
